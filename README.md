
# FlutterDesk

**A modern Flutter SDK manager for macOS.**

FlutterDesk is a desktop application designed to simplify Flutter SDK installation, version management, and switching between multiple Flutter versions.

Manage your Flutter development environment through a clean, intuitive interface.

## Features

- **SDK Management** — Install and manage multiple Flutter SDK versions.
- **Version Switching** — Switch between installed Flutter SDK versions.
- **SDK Information** — View installed versions and SDK details.
- **Modern Interface** — Simple, clean, and developer-friendly.
- **Cross-Platform Support** — Windows support is planned for a future release.

## Installation

### macOS

1. Download `FlutterDesk-macOS.dmg`.
2. Open the downloaded DMG file.
3. Drag FlutterDesk into the **Applications** folder.
4. Launch FlutterDesk from Applications.

> **Note:** macOS may display a security warning if the application has not been verified by Apple. Only open applications from sources you trust.

### Windows

FlutterDesk for Windows is planned for a future release.
